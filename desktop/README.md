# 抖音下载器 APP（图形界面版）

粘贴抖音链接（或整段分享文本）→ 批量下载**无水印**视频 + 封面 + 文案 + 元数据；另带「去水印」页，给已经带烧录水印的本地视频做区域修复。与命令行版共用同一个久经实测的解析引擎。

## Windows（主要用法）

**方式一：打包成独立 EXE（推荐，一次性的事）**

1. 电脑上有 Python 3 就行（没有就去 python.org 装一次，勾选 “Add python.exe to PATH”）。
2. 双击 **`打包成EXE.bat`**，等 1–2 分钟。
3. `dist` 文件夹里生成 **`抖音下载器.exe`** —— 单文件、免安装，拷到桌面/U 盘/别的 Windows 电脑双击就能用，之后不再需要 Python。

**方式二：不打包直接开**

双击 **`启动下载器.bat`**（需要电脑上装有 Python 3），界面一样。

**ffmpeg（可选）**：把 `ffmpeg.exe` 放到 exe（或脚本）旁边，「ffmpeg 后处理」（写入标题/作者元数据、嵌入封面、faststart）会自动生效；没有它也能下载，只是跳过后处理。去水印功能必须有 ffmpeg。

## macOS / Linux

```bash
bash build-mac-linux.sh   # 生成 dist/抖音下载器
```

或直接 `python3 douyin_app.py` 运行源码（需 Python 3 + tkinter）。

## 手机（安卓 / iPhone）

手机端走 **Web 版**（同目录的 douyin-web 服务）：部署到服务器后，用手机浏览器打开，点「添加到主屏幕」，图标和打开方式就和原生 APP 一样（已做 PWA 适配）。部署需要一台服务器，步骤见 Web 版 README。

## 功能清单

- 批量粘贴：链接、分享全文混着贴都能认；图集作品自动逐张下图
- 画质：自动探测多档选最大 / 锁定 1080p / 720p；断点续传 + 失败重试
- 产物：`<作者>-<标题>.mp4 / .jpg（封面）/ .txt（文案）/ .json（点赞/评论/转发/发布时间/音乐）`
- 去水印：左上/右下预设或自定义坐标，附处理前后对照图
- 设置自动保存（保存目录、画质偏好下次打开还在）

## 文件说明

| 文件 | 作用 |
|---|---|
| `douyin_app.py` | 图形界面（tkinter） |
| `app_core.py` | 逻辑层：把引擎输出接到进度条/日志 |
| `douyin_engine.py` | 解析下载引擎（与命令行版 douyin-dl.py 同一内核） |
| `打包成EXE.bat` / `启动下载器.bat` | Windows 一键打包 / 免打包启动 |
| `build-mac-linux.sh` | macOS/Linux 打包 |
| `icon.ico` / `icon.png` | 应用图标 |

## 边界

- 解析依赖抖音分享页的公开数据结构，平台改版可能导致失效，失效后更新 `douyin_engine.py` 即可（界面不用动）。
- 去水印是插值修复，不是还原：水印压着字幕/人脸时该区域会被涂抹。
